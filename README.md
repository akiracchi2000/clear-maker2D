# Clear Maker 2D - 語彙単語 写メ採点

高校生向けの現代文・語彙ノートの問題を画面に表示し、紙に手書きした単語答案をスマートフォンで撮影してAI採点するオンライン学習Webアプリ（PWA対応）です。

---

## 🌟 主な機能

- **スプレッドシート連動・問題データ非公開配信**:
  - 全94ページ・1,060問の問題データをGoogleスプレッドシートから安全に動的取得。
  - GitHub上に問題・模範解答を公開せず、カンニングを防止。
  - スプレッドシート側のテキストを編集するだけで、アプリの問題文が自動更新。
- **スティッキー語群バー**:
  - 画面上部に固定表示され、スクロール中も常時確認可能。
  - **使った語の消し込み（メモ機能）**: タップでグレーアウト＆取り消し線。
  - **語群折りたたみ**: 1行のコンパクト表示と全展開の切り替え。
  - **読みがな（ルビ）表示**: 語群の上にふりがなを表示可能。
- **動的体裁切り替え**:
  - 「対で覚える語」などは2問ペアのグループカードとして視覚的にわかりやすく自動配置。
- **日本語単語 手書き写メ採点（Gemini 3.7 Flash 連携）**:
  - 生徒は「問題番号と単語（漢字・カタカナ）のみ」を手書きして撮影・提出。
  - 最新のハイブリッド推論モデル（Gemini 3.7 Flash）により、漢字のトメ・ハネ・部首の正確性を厳密かつ高速に採点。
  - 単語の重複使用（繰り返し回答）を自動検出し、再提出を促す不正防止ルールを搭載。
- **苦手克服（Remedy）**:
  - 不正解ログをスプレッドシートに自動記録し、克服テストを実施可能。
- **生徒・管理者用 進捗ダッシュボード**:
  - 合格履歴カレンダー、クリア単語数、リアルタイムの克服状況グラフを可視化。
- **PWA対応**:
  - ホーム画面に追加してネイティブアプリ感覚で利用可能。

## 📁 ファイル構成

- `index.html`: 生徒用メイン画面
- `student.js`: 出題、撮影、採点、履歴、スプレッドシートAPI連携ロジック
- `student.css`: アプリデザイン（2D専用パープル基調）
- `student_dashboard.html`: 生徒・管理者用進捗ダッシュボード（GAS側Webアプリ用）
- `backend_GAS_spreadsheet.gs`: Google Apps Script用オールインワンバックエンド（AI採点・問題配信・進捗ダッシュボード・トークン管理）
- `vocabulary-question.json`: 語彙マスターデータ（全94ページ・1,060問）
- `build-vocabulary-bundle.ps1`: 語彙データバンドルおよびCSV出力用スクリプト
- `sw.js`, `manifest.json`: PWA・オフラインキャッシュ設定
